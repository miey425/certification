# 余白 — 資格勉強の記録

学習時間を記録する、シンプルなポモドーロタイマーです。記録はブラウザー内に保存されます。

## 公開URL

GitHub Pages: https://miey425.github.io/certification/

## GitHub Pages の設定

リポジトリの **Settings → Pages** を開き、**Build and deployment** の **Source** を **Deploy from a branch** にします。Branch は `main`、フォルダーは `/(root)` を選んで保存します。

このサイトは静的ファイルだけで動くため、ビルド手順や追加の依存パッケージはありません。設定後、GitHub Pages が公開を完了すると上記URLで開けます。
